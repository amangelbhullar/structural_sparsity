# Structural Sparsity for Knowledge Graph Completion

Code for **"Structural Sparsity for Knowledge Graph Completion: Hard, Structure-Conditioned, and Query-Adaptive Edge Gating"** (IEEE Transactions on Knowledge and Data Engineering, submitted 2026).

This repository implements and evaluates three sparse edge-gating variants for GNN-based knowledge graph completion (KGC), differing only in what information the gate conditions on:

- **HS-GNN** — hard, relation-only gate: β_jri = β_r, a single learned scalar per relation type.
- **AS-GNN** — structure-conditioned gate: β_jri = f([h, r, t]), conditioned on the full triple.
- **ASR-GNN** — query-adaptive gate: β_jri = f([h, r, t, q]), additionally conditioned on the query.

All three share the same encoder-decoder architecture, embedding dimension, and training budget; gate conditioning granularity is the only independent variable.

## Key Finding

No single gate granularity dominates across all benchmarks. HS-GNN's relation-only gate significantly outperforms both triple-conditioned variants on FB15k-237, WN18RR, and YAGO3-10, while AS-GNN's triple-conditioned gate significantly outperforms HS-GNN on CoDEx-S and CoDEx-M (tied on CoDEx-L). We attribute this split to **relation polysemy**: on graphs where relation types carry consistent semantics regardless of the entities they connect (WordNet, Freebase, YAGO), a relation-only gate is sufficient and cheaper; on graphs with higher relation polysemy (CoDEx), gating on entity identity recovers information a relation-only gate structurally cannot represent.

## Results Summary

| Dataset | Best Model | MRR (%) |
|---|---|---|
| FB15k-237 | HS-GNN | 33.12* |
| WN18RR | HS-GNN | 15.74* |
| YAGO3-10 | HS-GNN | 17.58* |
| CoDEx-S | AS-GNN | 42.60* |
| CoDEx-M | AS-GNN | 32.85* |
| CoDEx-L | AS-GNN (tie) | 27.46 |

\* statistically significant over runner-up, paired t-test, p < 0.05, n = 10 seeds. Full results, baselines, and significance testing are in the paper (Tables III-VI).

## Reproducing Results

Each (dataset, model, seed) configuration is trained as an independent job:

```bash
python src/train.py --model hs-gnn --dataset FB15k-237 --seed 0 --epochs 150
```

All three gate variants use a 200-dimensional entity/relation embedding, a 200-dimensional message-passing hidden layer, Adam optimizer (lr = 1e-3), batch size 1,024, and sparsity regularization coefficient lambda = 1e-4 (fixed per dataset across all three models). Results are averaged over 10 random seeds per (model, dataset) pair.

To aggregate per-seed results into summary tables:

```bash
python aggregate_results.py --results-dir results/
```
